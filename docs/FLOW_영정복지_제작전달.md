## 0. 공통 척추 (모든 채널 동일)

```text
[자격] 복지과·위탁 자격 확인
   ↓
[동의] 본인·가족·대리 초상·개인정보 동의
   ↓
[접수] 채널 코드로 건 생성 (A~D)
   ↓
[제작] 단정 영정 생성 (셀카 또는 기존 사진)
   ↓
[검수] 담당·복지사·가족 확인 (선택/필수 협의)
   ↓
[물리] 인화 + 액자
   ↓
[전달] 수령·인수인계
   ↓
[실적] 건수·단가·만족 · 재원 정산
```

| 단계 | 산출 | 잠금 포인트 |
| --- | --- | --- |
| 자격 | 대상 ID / 바우처 코드 | 중복·부정 방지 |
| 동의 | 동의서·대리권 | 목적 외 사용 ✗ |
| 접수 | 채널 태그 A~D | 실적·정산 귀속 |
| 제작 | 영정 PNG | 여권·공인 카피 ✗ |
| 검수 | 승인 플래그 | 잘못된 인물·톤 차단 |
| 물리 | 인화+액자 세트 | BOM 단일 |
| 전달 | 수령 서명 | 분실·재발송 규칙 |
| 실적 | 월간 집계 | 시·도·기금 보고 |

## 1. 접수 채널 4축

### A. 본인 촬영·접수

| 항목 | 내용 |
| --- | --- |
| 누가 | 본인 또는 동거 가족 |
| 어디서 | 집·주민센터 안내 QR |
| 어떻게 | 바우처 링크 → 셀카 업로드 → 생성 |
| 전달 | 자택 택배 / 읍면동 수령 / 복지관 픽업 |
| 강점 | 속도·프라이버시·행정 부담↓ |
| 약점 | 디지털 약자·촬영 품질·대리 동의 |

**운영 팁:** 큰글씨 안내 1장 · 실패 시 B/C로 이관 버튼.

### B. 사회복지단체 일괄

| 항목 | 내용 |
| --- | --- |
| 누가 | 종합사회복지관·장애인복지관·노인복지관 등 |
| 어디서 | 단체 프로그램·방문 일정 |
| 어떻게 | 명단+동의 → 단체 코드로 **배치 업로드** → 일괄 생성·일괄 발주 |
| 전달 | 단체 일괄 수령 → 개별 배분 |
| 강점 | 규모·원가·물류 효율 · 시범에 적합 |
| 약점 | 일정 동기화·개인차 품질·단체 인력 |

**운영 팁:** N명 묶음 발주(예: 10·20·50) · 단체 담당자 1인 검수 창구.

### C. 복지사 (사례관리)

| 항목 | 내용 |
| --- | --- |
| 누가 | 읍면동·희망복지지원단·사례관리 복지사 |
| 어디서 | 가정방문·상담실 |
| 어떻게 | 복지사 태블릿/폰으로 대리 접수 · 기존 사진 스캔도 허용 |
| 전달 | 복지사 전달 또는 방문 동봉 |
| 강점 | 취약·독거·디지털 약자 커버 |
| 약점 | 복지사 업무 부하 · 대리 촬영 윤리 |

**운영 팁:** 복지사 전용 간편 모드(단계↓) · 건당 행정보조 시간 한도 · 기존 가족사진 경로 우선.

### D. 그외 가능한 자원 (확장)

| 코드 | 자원 | 역할 | 비고 |
| --- | --- | --- | --- |
| D1 | **읍면동·주민센터** | 창구 접수·QR·서류 | A의 오프라인 거점 |
| D2 | **경로당·노인교실** | 집단 안내·보조 촬영 | B에 가깝게 운영 |
| D3 | **요양원·주야간보호** | 시설 일괄·보호자 동의 | 초상·대리권 중요 |
| D4 | **방문간호·돌봄 요원** | 현장 대리 접수 | C와 연계 |
| D5 | **자원봉사자·재능기부** | 촬영 보조·안내 | 검수는 공식 담당 |
| D6 | **종교·봉사단체 CSR** | 장소·인력·현물 | 재원·신뢰 보완 |
| D7 | **지역 사진관·인화점** | 난이도 높은 건 보조·재촬영 | 단정 생성 실패 백업 |
| D8 | **장례식장·상조 (안내만)** | 긴급 안내·바우처 안내 | 영업 끼워팔기 ✗ · 톤 주의 |
| D9 | **보호자·후견인** | 대리 동의·기존 사진 | 법·동의 양식 |
| D10 | **병원 원무·의료사회복지** | 말기·퇴원 연계 | 민감 · 시범 후순위 |
| D11 | **의회·의원실 민원 창구** | 정책 안내·연계 | 행정 결재와 분리 |
| D12 | **협력 인화·액자 업체** | 제작 후단·지역 픽업 | 전달 거점 |

시범 우선순위 제안: **A + B + C** 먼저 · D는 거점만(D1·D3) 붙이고 확장.

## 2. 채널별 제작→전달 스윔레인

### A 본인

```text
본인/가족 → (자격코드) → 단정 생성 → (선택 검수) → 인화·액자 → 택배/픽업 → 실적
```

### B 단체 일괄

```text
복지과 명단 → 단체 동의 취합 → 배치 업로드 → 일괄 생성
    → 단체 검수 → 일괄 인화·액자 → 단체 수령 → 개별 배분 → 실적
```

### C 복지사

```text
사례 선정 → 방문·동의 → 대리 업로드(또는 기존사진)
    → 생성 → 복지사/가족 확인 → 인화·액자 → 방문 전달 → 실적
```

### D 확장 (예: 요양원)

```text
시설·보호자 동의 → 시설 일괄 촬영/기존사진 → B와 동일 후단
```

## 3. 상태 머신 (운영 칸반)

| 상태 | 의미 | 다음 |
| --- | --- | --- |
| `eligible` | 자격 확인됨 | 접수 |
| `consented` | 동의 완료 | 제작 |
| `draft` | 생성 중/대기 | 검수 |
| `review` | 검수 대기 | 승인/반려 |
| `print` | 인화·액자 발주 | 배송 |
| `shipped` | 출고 | 수령 |
| `delivered` | 수령 완료 | 마감 |
| `closed` | 실적 반영 | — |
| `hold` / `reject` | 보류·반려 | 사유 기록 |

채널 태그: `ch=A|B|C|D1…` · 재원 태그: `fund=city|province|welfare|csr`

## 4. 전달 옵션

| 방식 | 적합 채널 | 메모 |
| --- | --- | --- |
| 자택 택배 | A · C | 주소·수령인 확인 |
| 읍면동·복지관 픽업 | A · B · D1 | 분실↓ · 내방 부담 |
| 단체 일괄 납품 | B · D3 | 시범 기본 추천 |
| 복지사 방문 동봉 | C · D4 | 취약 대상 |
| 협력점 픽업 | D7 · D12 | 지역 거점 |

재발송·파손: 1회 무상(협의) · 이후 사유별.
