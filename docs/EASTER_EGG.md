> **바이럴 계획안:** [`EASTER_VIRAL.md`](EASTER_VIRAL.md) (overt / true easter · **로또=구상중** · 연구 로그)

## 구조

| 슬롯 | 역할 |
|------|------|
| 2장 | 정상 단정 (TONE + LIGHTING + identity 그대로) |
| **1슬롯** | 확률 당첨 시에만 **워터마크 오버레이** (프롬프트로 개·고양이·기호를 장면 안에 넣지 ✗) |

생성은 **항상 클린 3컷**. 이상함 = 합성 레이어만.

## 요소 (워터마크)

- **기본 (glyph):** 모서리·어깨 쪽 기호 · 숫자 · `?` · 외계 느낌 글리프 — “이게 뭐지?”
- **퍼니 희소일 (animal variant):** 작은 fun mark (`?` · `※` · `◈`) — 장면 소품이 아닌 **마크**
- 여권·관공서·민원 농담 **금지**
- 얼굴 중앙은 비움 (제출용 단정 컷과 혼동 방지)

## 확률

| 구간 | 이스터 확률 (3장 중 1슬롯) | 비고 |
|------|---------------------------|------|
| 평일 (normal) | 0.5–2% (기본 **1%**) | 거의 안 나옴 |
| 시즌 주간 (season) | 5–10% (기본 **7.5%**) | 취업·신학기 |
| **연간 희소일** (scarce) | 30–50% (기본 **40%**) | 캘린더 고정 |
| 퍼니 희소일 (fun) | scarce와 동일 + **animal 마크** | 만우절 등 |

희소일 플레이스홀더 (코드 `src/lib/easterEgg.ts`, env 덮어쓰기 가능):

| MM-DD | kind | 라벨 |
|-------|------|------|
| 04-01 | fun | 만우절 |
| 03-02 | scarce | 봄 취업 희소일 |
| 09-01 | scarce | 신학기 희소일 |
| 11-20 | scarce | 수능 다음날(근사) |

시즌 주간 예: `02-24`–`03-09`, `08-25`–`09-07`.

## 클린 보관 · 워터마크 제거

| 레이어 | 역할 |
|--------|------|
| `previewVault` / asset | **항상 클린 PNG** |
| `imageUrl` (이스터 슬롯) | 워터마크 합성본 — 미리보기·다운로드 기본 |
| `imageUrlClean` (옵션) | 같은 슬롯 클린 data URL (클라이언트 힌트) |

**제거 경로 (v1 이후 / 업셀):**

1. **권장:** vault 클린을 `easterStrip=true`로 내려줌 → “워터마크 제거 / 희소 클린 저장”
2. vault 만료 시: 같은 unlock으로 **클린 재생성**(이스터 롤 없이) 문서화 — 현재 생성은 프롬프트 이스터 없음

다운로드·이메일·추가컷 API는 `easter` + `easterVariant`면 vault 클린에 워터마크를 **재합성**. `easterStrip=true`면 클린 그대로.

## 매출 시나리오

1. 이스터 컷 **「희소 컷 저장」** / 이후 **「워터마크 제거」** 업셀
2. 같은 이상함 **인화 CTA** (플러스·키오스크) — 마크 포함본
3. 공유 워터마크 “단정 이스터” → 유입
4. 희소일 **유료 리롤** 1회
5. 옵트아웃 **「깔끔 3장만」** (안심형)

## 가드

- 라벨: **보너스 / 희소** — 공식 제출·이력서용 **비권장**
