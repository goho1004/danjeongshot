## Intent (온도 · 사기 아님)

**Desire temperature (원하는 공기):**

> something leaked → briefly looked like a glitch/defect → got patched → evidence (serial) remains

즉: “잠깐 샌 것 같음 → 결함/글리치처럼 보임 → 패치됨 → **시리얼·증거는 남음**” — 커뮤니티가 스스로 퍼뜨리는 온도.

**명시적 금지 (Intent ≠ fraud):**

- 가짜 소송 · 가짜 피해 클레임 · 가짜 합의 연극
- 불법·기만 광고
- “진짜 사고인 척” 법적 드라마로 에스컬레이션

병행 장치(이미 제품 방향과 정합): **희소(scarcity)** + **진품/인증(serial, verify)** — 워터마크는 제거 가능.

## Two lanes (+ 로또 research)

### 1. Overt theme easter (만우절·할로윈·퍼니)

- 예: UI가 12:17에 갑자기 어긋남 → 수분 내 복구
- 반응 나오면 다각도 후속: behind-the-scenes · serial auth · coupon · partner
- **안전 레인:** 이벤트임을 전후 필요 시 라벨링 ( overt )

### 2. True easter (scarcity viral)

- 극저확률 워터마크
- 브랜드 **침묵** — 커뮤니티가 발견
- `/v/{code}` 진품 인증
- 수량 캡
- 공식 인정은 **유기적 확산 이후**에만 nod

| | Overt | True |
|--|-------|------|
| 브랜드 발화 | 전후 라벨 OK | 침묵 → 늦게 nod |
| 목적 | 시즌 이벤트·퍼니 | 희소 바이럴 |
| 위험 | 낮음 | 가짜 드라마로 가면 ✗ |

### 3. 로또 이스터 — **구상중 (research only · 제품 빌드 ✗)**

> **이 내용 그대로 잠금.** 제품 구현·배포·성장엔진화 ✗. 연구 메모만.

| | |
|---|---|
| **Status** | **구상중** · **미구현** · **자문 전 실험 신중** |
| **Why bait** | 로또 = 온국민 관심 · 매주 리셋 · 바이럴 먹잇감 1순위급 |

**Beat / tone**

- 추첨 **발표 직후** 해당 회차 번호 반영한 단정풍 컷 발행 (예: 8/1 추첨분이면 그 직후)
- 출처 흐림 · 공식 「예언·맞춤」발화 ✗
- 바이럴 = **3자** 「이 사진 뭐죠?」→ 번호 **해독**
- 본인이 나와 인터뷰·예언 인증 = 보도/PR이지 바이럴 아님
- 공식 1차 멘트(필요 시): 셀카/파이프라인 **이물질** · 단정 필터 미검출 **기술적 사과** · 보완·기술투자 약속 — 예언 인정 ✗
- 순서는 「센 거 후 소소한 이스터」· 이스터를 본체 성장엔진으로 키우기 ✗ · 주간 토픽에 얹는 미끼

**Legal / risk (합의 유지 · 그린라이트로 완화 ✗)**

- 「피해자·고소주체 없음」만으로 면책 ✗ (행정·플랫폼 가능)
- 발표 후 제작이라도 시간 오인(발표 전처럼) 설계하면 표시광고 리스크
- 자문 받을 것 · 동행복권 마킹지/로고 직복제 주의
- 문닫고 단정2 = 이득 프레임 ✗
