## 0. 한눈에 — 대리점 단일 모델 (잠금 2026-08-02)

> **B2B·개인 모두 대리점.** 장부·코드·QR·집계는 하나. 타입·율·세무·지급주기만 다름.

| 타입 | 대상 | 율(결제액·코드별) | 세무 | 지급 주기 (마케팅) |
|------|------|-------------------|------|-------------------|
| **법인 대리점** | 인력아웃소싱 대형 등 | 보통 **40~50%** (코드별) | **세금계산서** | **월** 또는 **주** |
| **개인 대리점** | 모바일·소개·소호 | 보통 **15~25%** (기준 20) · 사장급 10~20 | **원천징수** | **주** · 이상적으로 **일 / 즉시** |
| 예외 | 초대형 독점 | ~70% 협의 | 계산서 | 월·주 협의 |

**운영 단위**

| 키 | 규칙 |
|----|------|
| **대리점코드** | 분류·귀속·대장의 키 (`?partner=XXXX` / QR) |
| **인센율** | **코드마다 다름** · 결제 시점 `rateSnapshot` |
| **인증** | 대리점별 **QR 또는 코드 입력** |
| **계산** | 자동 집계 → 엑셀/정산서 · 송금은 승인(P1)→자동(P2) |
| **스택** | 한 결제에 코드 **1개만** · 학내·쇼츠 할인과 인센 스택 ✗ |
| **근본** | **무자본창업** — 선수금·자기자본 0으로 시작 (폰·링크만) |
| **가맹비** | **있다** · 선수 현금 ✗ · 정산 유보로 **분할 충당** 후 확정 (§4-3) |
| **환불보증 유보** | 충전 중 성격 · 당기 ≤GMV **5%** → 목표 월GMV **20%** · 최장 1년 (§4-3) |

**절대:** 동일 결제에 복수 대리점 인센 풀스택 ✗.  
**공식 명칭:** 가맹점·영업지역 공식 표기 ✗ · **대리점 / 안내 파트너 / 제휴 ○**.  
**훅(숏폼·당근):** 「핸드폰만으로 사진관 개업」**허용** · **무자본창업** · 「선수 가맹비 없음 · 가맹비는 정산으로」· 유보→가맹비 고지.

## 4. 정산 프로세스 · 지급 주기 (잠금)

```text
결제 confirm → 대리점코드 귀속 + rateSnapshot
  → 주기별 집계(환불·차지백 차감) → 정산서(엑셀/웹)
  → 세무(법인=계산서 / 개인=원천) → 이체
```

### 4-1. 지급 주기 (마케팅 잠금 · 2026-08-02)

| 대리점 타입 | 맞는 주기 | 이유 |
|-------------|-----------|------|
| **법인 (B2B)** | **월** 또는 **주** | 계산서·내부 결재 · 대량 건수에 맞춤 |
| **개인** | **주** (기본 목표) · 이상적 **일 / 즉시** | 동기·신뢰 · “바로 들어온다”가 모집 훅 |

구현 단계와 맞추기:

| 단계 | 법인 | 개인 |
|------|------|------|
| P0 파일럿 | 주·월 수기 | 주 수기 (즉시 약속 ✗) |
| P1 집계 | 주 또는 월 자동 정산서 | **주** 자동 정산서 · 승인 이체 |
| P2 송금 | 주/월 cron | **일 배치** 또는 최소액·홀드 후 **준즉시** |

- 개인 **즉시** = 결제 confirm 직후 송금 ✗ 권장 아님 → 환불 홀드(예: 수일) 둔 **일 배치/준즉시**가 현실적  
- 최소 지급액·홀드 규칙은 타입별 대장에 기록

### 4-2. 자동화 Phase

| Phase | 온라인 | 자동 | 내용 |
|-------|--------|------|------|
| **P0** | 반 | ✗ | 대리점 마스터 시트 · 수기 · 이체는 사업자 후 |
| **P1** | ○ | 집계·정산서 | 코드 귀속 · 엑셀/웹 정산서 · **송금=승인** |
| **P2** | ○ | 송금까지 | 타입별 cron(주/일) + 지급 API · 이상 건만 사람 |

- 주문에 `partnerCode` + `ratePctSnapshot` **코드 있음** (`orders.ts`) · 메모리 장부 `agentLedger` — **durable DB·실송금·어드민은 아직 ✗**  
- 파일럿 고지: 「실적 기록 · 현금 정산은 사업자·시스템 후」  
- 상세: [`AGENT_PARTNER_PLAN.md`](AGENT_PARTNER_PLAN.md) §16

### 4-3. 무자본창업 · 분할 가맹비 (잠금 2026-08-02)

> **근본 = 무자본창업.** 선수금·자기자본 0으로 시작 (폰·링크만).  
> **가맹비는 있다** — 현금으로 먼저 받지 않고, 정산 유보로 **분할 충당**한 뒤 확정 입금.  
> **유보 램프 = 가맹비 분할 납부 장치** (겸 환불·차지백 완충). 성장동력은 **인센 네트워크**(유보 ≠ 성장동력).

| 구간 | 성격 | 대리점 청구권 |
|------|------|----------------|
| 시작 | **무자본** — 납입 0 | — |
| 충전 중 (`accruing`) | **환불보증 유보** (부채·제한현금) + 가맹비 충당 중 | 환불 상계 ○ · 임의 인출 ✗ |
| 목표 도달 후 **전환** (`converted`) | **가맹비 매출** (손익) | **반환청구권 소멸** (계약 고지) |
| 전환 이후 | 소액 **운영 환불버퍼** 별도 (실측 후) | 가맹비와 장부 분리 |

| 항목 | 잠금 |
|------|------|
| **당기 유보 상한** | **GMV 5%** (섭섭 선) |
| **가맹비 목표** | **기준월GMV × 20%** (인센 ~20%면 ≈ 인센 1개월분) |
| **기준월GMV** | **직전 3개월 평균 GMV**(없으면 해당 월) |
| **충당기간** | 목표 **4–6개월** · **최장 12개월** 내 달성 |
| **차감** | 지급 인센에서 당기유보만큼 (별도 현금 입금 ✗) |
| **상계** | 코드 귀속 환불 → 유보 잔고에서 **우선** 차감 |
| **전환** | 잔고 ≥ 목표 → 가맹비 확정 입금 · 미달 시 계속 충전 |
| **고지** | 「무자본으로 시작 · 선수 가맹비 없음 · 가맹비는 정산으로 최대 5%/주기 · 월매출 20%분 · 4–6개월(최장 1년)」 |

### 4-3-a. 5% → 20% 램프 · 전환 (잠금 2026-08-02)

```text
가맹비목표 = 기준월GMV × 20%
부족분     = max(0, 가맹비목표 − 현재유보잔고)
당기유보   = min(당기GMV × 5%, 부족분)   # franchiseFeeStatus=accruing 일 때
당기지급   = 인센 − 당기유보 − 환불상계
환불       = 잔고 상계 우선 · B2B는 다음 계산주기에서 감 가능
전환       = 잔고≥목표 → franchiseFeeStatus=converted · 반환청구권 소멸
```

**충전 감각 (매출 안정)**  
주기당 최대 5% × **약 4주기** ≈ 월GMV 20% 목표.  
개인 주정산 ≈ **한 달 전후** · 법인 월정산 ≈ **4–6개월** · 최장 **1년**.

| 타입 | 감·정산 | 체감 |
|------|---------|------|
| **법인 B2B** | 환불·상계는 **다음 계산주기**에서 감 | 램프 동일 · 계약명 「파트너 보증·가입분」병기 가능 · **선수 현금 ✗** |
| **개인** | 동일 | 충당 중만 실수령 ↓ · **전환 후** 당기유보≈0 · 환불버퍼만 |

**전환 이후**  
가맹비는 회사 매출로 확정. 운영 환불버퍼는 별도 장부(기본 0 → 실환불×1.05 검토).  
본사 손익 환불버퍼(§3 GMV 3%)와 **별개**.  
프로토 convert 자동화는 P1 (`franchiseFeeStatus`).
