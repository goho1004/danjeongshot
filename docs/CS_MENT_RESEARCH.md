## CS 대응 1단계 (모든 품질·재생성 CS)

1. **상대 톤 맞춤** — 담담/화남/짧음에 맞는 1차 멘트  
2. **불만족 사진을 카톡에 올려 달라**고 요청  
3. **요구 반영**해 옆창 Gemini 생성 → PNG를 카톡에 붙여넣기  
4. **단정·신뢰 마무리** 2차 멘트 (`qa2_full` 추천 · `— 단정샷`)

정책은 하나, 말투는 여러 개. 선별은 사람(`/ops/cs`).

## 톤 코드 (`tone`)

| tone | 쓸 때 |
|------|--------|
| empathy | 화남·실망 · 공감 한 줄 |
| policy | 환불·관공서 경계 |
| guide | 다음 행동(링크·셀카·요청) |
| short | 사진 이미 옴 · 캡션 |
| escalate | 중복·위협 → 사람/TG |
| close | 단정·신뢰 마무리 · 종결 |
