## B2B: 인력아웃소싱 대형 · 임원→하향 살포 · 인센 정산 (잠금 2026-08-02)

> **채널 정본 요약:** [MARKETING_CHANNEL.md](MARKETING_CHANNEL.md)
> 메모·연구용 · 당장 구현 ✗
> **회장님 계획:** 아는 **인력아웃소싱 대형** 위주 · **임원급에서 밑으로** 조직 내 배포 · **인센 정산**.
| 항목 | 초안 |
|------|------|
| **타깃** | 인력아웃소싱·파견·채용대행 **큰 곳** (중소 산발 ✗ · 대형 우선) |
| **진입** | 회장님 네트워크 → **임원급 미팅** 먼저 (현장 영업 먼저 ✗) |
| **살포** | 임원 승인·권고 → 지점·팀장·현장 매니저·상담원 순 **하향** |
| **니즈** | 구직자·이직자 **이력서·프로필 사진**을 업체 쪽에서 빠르게 |
| **정산** | **인센** — 사장급 10~20% / 법인 B2B 40~50% (아래 §인센율 · 미확정) |
| **형태(연구)** | ① 업체·지점·담당자별 추적 코드 ② 건당 인센 대장 ③ 월 정산·세금계산서 |
| **단정 포지션** | 여권·관공서 ✗ 고지 유지 · 민간 이력서·링크드인용 |
| **학내 70%와 관계** | B2B 인센·단가는 **별도** (학내·쇼츠 할인과 스택 ✗) |

### 인센율 초안 (회장님 제안 · 2026-08-02 · 미확정)
| 유형 | 율(결제액 기준) | 의미 |
|------|-----------------|------|
| **사장·임원급 소개/인센** | **10~20%** | 개인·임원 라인 귀속 · 하향 살포 대가 |
| **B2B 법인 계약(업체 마진)** | **40~50%** | 업체가 단가·정산을 잡는 **도매/채널 마진** |
**구분:**
- **10~20%** = 사람(사장·임원·담당) **리베이트/인센**
- **40~50%** = **법인 B2B** 채널 마진
- 둘 **풀스택 동시 ✗** — 택1 또는 법인 마진 안에서 내부 인센 쪼개기
**쪼개기 예시(연구):** 법인 40% → 그중 일부가 임원·지점 인센 · 단정 쪽은 Gemini·PG·환불 버퍼 후 순마진 검증 필수.

### 운영 흐름 (초안)
1. 대형 아웃소싱 **임원** 대면 → 가치(속도·단정·원가) + 인센 구조 설명
2. 임원이 **내부 전파** (지점장·채용팀·현장) — 단정이 밑에서 뚫지 않음
3. 담당자별/지점별 **추적 링크·코드**로 결제·컷 수 집계
4. 합의 주기(월 등)에 **인센 정산** 지급

## 캠페인: 쇼츠 댓글 × 넘버링 QR × 50% (잠금 2026-08-02)
> 무작위 살포 ✗ · **쇼츠에 댓글 단 유저에게만** 개인/회차별 QR·코드 지급.
| 항목 | 내용 |
|------|------|
| **대상** | 단정 쇼츠(숏폼)에 **댓글 남긴 유저** |
| **혜택** | 결제액 **50% 할인** (기본팩·플러스 적용 범위는 구현 시 확정) |
| **매체** | **넘버링 QR** (+ 동일 번호 쿠폰코드 병행 권장) |
| **URL 초안** | `https://danjeongshot.vercel.app/make?promo=DJS50-####` (`####` = 일련번호) |
| **추적** | 번호별 1회(또는 N회) 사용 · 누가/어느 쇼츠에서 나갔는지 시트·DB에 기록 |
| **배포** | 댓글 확인 후 DM/답글로 QR 이미지 또는 링크 · **공개 댓글에 전 번호 나열 ✗** |

### 운영 규칙 (초안)
1. 쇼츠 고정댓글: 「댓글 남기시면 50% 할인권(번호 QR) 드려요」정도만 — **코드 본문 노출 ✗**
2. 번호는 `DJS50-0001` … 순번 · 회장님/운영이 지급 대장에 체크
3. 중복·재판매·공개 공유 시 해당 번호 폐기
4. **실결제(토스 라이브)·쿠폰 API 붙인 뒤** 집행 · 지금은 샌드박스라 정책만 잠금
