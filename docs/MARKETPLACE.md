## 4. 돈의 흐름

| 항목 | 규칙 |
|------|------|
| 소비자가 | 기본 ₩9,900 / 플러스 ₩14,900 |
| 인센 | 코드별 율 · 결제 confirm 귀속 |
| 근본 | **무자본창업** (선수금 0) |
| 가맹비 | **있다** · 선수 현금 ✗ · 유보 램프로 분할 충당 후 **확정 입금** |
| 환불보증 유보 | 충당 중(`accruing`) 성격 · 환불 상계 우선 |
| **당기 유보** | **≤ GMV 5%** (섭섭 선) |
| **가맹비 목표** | **기준월GMV × 20%** · 4–6개월(최장 1년) · 인센20%면 ≈ 인센 1개월분 |
| 전환 후 | `converted` · 반환청구권 소멸 · 운영 환불버퍼 별도 |
| B2B 환불 | **다음 계산주기**에서 감 |

```text
당기유보 = min(GMV×5%, 가맹비목표 − 현재잔고)  # accruing
실수령   = 인센 − 당기유보 − 환불상계
전환     = 잔고≥목표 → 가맹비 매출 확정
```

**감각 · 월 30건 · 기본가 · 인센 20% · 유보 5% 충당 중**  
GMV ₩297,000 → 인센 ₩59,400 → 유보 ₩14,850 → **실수령 ≈ ₩44,550**  
가맹비 확정 후(환불 0) → **≈ ₩59,400**
